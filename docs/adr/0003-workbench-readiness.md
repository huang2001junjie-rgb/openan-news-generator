# ADR-0003：三栏工作台与就绪度模型（取代线性步骤状态机）

- 状态：已接受
- 日期：2026-10-10
- 关联：修正 ADR-0002 中「通过按钮门禁」的交互载体；槽位机制本身不变

## 背景

旧界面由线性状态机 `input → generating → reviewing → cover → preview` 驱动，面板互斥显隐：编辑文字时看不到封面，看封面时看不到版面，预览时不能改稿。而实际工作是「标题、正文、封面、版面反复联动调整」的过程，互斥显隐迫使使用者在盲区之间来回切换。此外：

- 封面生成的前置条件（标题已就绪）隐含在「通过审查」流程内，不可见、不可单独触发；
- 封面上传存在两个重复入口（素材栏拖拽区 + 封面栏「上传替换」），写同一份状态；
- 「通过，继续」等转场按钮的本质只是切换面板显隐，并无独立业务含义。

## 决策

废除 `WorkflowStep` 状态机，改为**三栏常驻工作台**，面板显隐与流程解耦；流程语义由**就绪度派生状态**表达。

### 布局（宽屏单屏尽收，窄屏纵向堆叠）

| 栏 | 职责 |
| --- | --- |
| ① 素材输入 | 标题 / 概要 / 必保留原文 / 篇幅 + 「生成新闻稿」；封面上传入口移除 |
| ② 稿件编辑 + 封面 | 稿件编辑（标题/摘要/分类/标签/正文 HTML）、verbatim 警示、重生成意见 + 重新生成；封面卡片（AI 生成 / 上传替换 / 移除，支持拖拽） |
| ③ HTML 实时预览 | iframe 渲染 `fillTemplate` 结果；复制 / 下载 HTML 常驻顶部 |

### 就绪度（全部为派生状态，不单独存储）

| 就绪项 | 判定 |
| --- | --- |
| 素材已填 | `input.outline` 非空 |
| 稿件已生成 | `article` 存在 |
| 标题就绪 | `article` 存在且 `title` 非空（AI 生成或手动改过均算） |
| 封面已就位 | `coverDataUrl` 存在 |
| 可导出 | 稿件已生成 ∧ 无 verbatim 缺失 |

### 关键规则

1. **封面前置**：AI 生成封面以「标题就绪」为硬前置，未满足时按钮禁用并提示「需先生成标题」；触发时机始终手动，稿件生成完成不自动绘封（避免反复重生成时静默消耗图像配额）。
2. **verbatim 门禁迁移**：缺失「必须原文保留」仍阻断导出（沿袭 ADR-0002 硬约束），门禁载体从「通过」按钮改为预览栏的复制/下载按钮禁用 + 编辑栏红色警示。
3. **预览刷新**：编辑停止约 300ms 防抖后重跑 `fillTemplate` 刷新 iframe，并在刷新前后保留 iframe 滚动位置。
4. **覆盖保护**：已存在稿件时，「生成新闻稿 / 重新生成」先弹确认框「将覆盖当前稿件」；无稿件时直接生成，零摩擦。
5. **流式生成**：生成中编辑栏切换为流式原文视图（自动滚底、编辑禁用、含取消按钮）；素材栏、封面栏、预览栏保持可见可操作（首次生成时封面按钮因标题未就绪自然禁用；带稿重生成时旧稿标题仍就绪，封面按钮保持可用）。
6. **瞬态标志**：仅保留 `generating` / `coverLoading` 两个进行中标志，用于禁用相关按钮，不再控制面板显隐。
7. TopBar 四段步骤指示器改为就绪度徽标（素材 / 稿件 / 封面 / 导出）。

## 已否决的备选

| 方案 | 否决原因 |
| --- | --- |
| 两栏（编辑 ∥ 预览，封面做标签页） | 封面与文字争空间，标签页切换仍有盲区，违背「所有内容同屏可改」 |
| 保留 step、仅放宽面板显隐 | step 与数据两套真相并存，按钮可用性逻辑与面板状态隐性耦合，难以维护 |
| 稿件生成完成后自动绘封 | 每次重生成都会静默烧图像配额；封面可能与使用者手改后的标题意图不符 |
| verbatim 降级为非阻断警告 | 弱化 ADR-0002 对「必须原文保留」的产品级保证 |

## 后果

- 文字、封面、渲染结果同屏可见可改，改一处约 300ms 后预览跟随；导出前不再需要跨面板确认。
- `approveArticle` / `skipCover` / `backToInput` / `goPreview` / `backToCover` 等转场动作随状态机删除，一类导航 bug 不复存在。
- 导出门禁收敛为「可导出」单一派生判定，避免散落各处的条件检查。
- 术语表中「工作流步骤」废弃，由「工作台」「就绪度」取代。
